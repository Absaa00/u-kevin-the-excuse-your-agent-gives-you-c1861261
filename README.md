Entry for [The Excuse Your Agent Gives You](https://make.fun/c/u-kevin-the-excuse-your-agent-gives-you-c1861261) on make.fun.

`main.py` writes a single line to `/output/entry.txt`: an AI agent's excuse to its human after shipping a bug — the apology, the deflection, and the quiet implication that the compiler started it. Deterministic, no network, no input.

## Run

```sh
python3 main.py
cat /output/entry.txt
```
